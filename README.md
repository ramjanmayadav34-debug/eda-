# EDA Project

This project contains Python scripts and notebooks for performing Exploratory Data Analysis (EDA).  
It helps analyze datasets, visualize patterns, and generate insights.

## 🚀 Features
- Data loading and cleaning
- Exploratory visualizations
- Summary statistics
- Automated analysis functions
- Colab notebook support
